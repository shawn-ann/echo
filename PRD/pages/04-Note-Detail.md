# 笔记详情页需求文档（04-Note-Detail）

**所属**：地道英语纠错 · 智能笔记本 | **版本**：V1.2 | **日期**：2026年8月
**对应功能**：F-02 一键记笔记（查看与编辑部分） | **依赖**：`pages/02-Correction.md` §7 错误类型分类、Overview §8.2 数据关系

## 1. 页面目标与入口

- **目标**：查看单条笔记的完整内容，并可编辑用户备注
- **入口**：笔记列表页（`pages/03-Notes-List.md`）点击卡片进入
- **出口**：返回笔记列表；如为语块笔记，可跳转查看来源报告（定位到纠错主页大会话中的对应消息，V1.1 增强，本期可选）

## 2. 页面结构

```
┌─────────────────────────────────────────────┐
│ 顶部导航：Logo | 新纠错 | 错题笔记        │
├─────────────────────────────────────────────┤
│ ← 返回笔记列表                               │
│                                             │
│ [类型标签]  创建时间                         │
│                                             │
│ 错误原文（原文语块，红色）                    │
│ ✅ 最小修正                                  │
│ 🌟 地道表达                                  │
│ 💡 错因/知识点解释                           │
│                                             │
│ 备注编辑区（可编辑 + 保存）                   │
└─────────────────────────────────────────────┘
```

## 3. 功能与交互细节

### 3.1 笔记内容展示

- 展示笔记全部字段：类型标签、错误原文、最小修正、地道表达、错因解释、创建时间
- 视觉配色遵循 `pages/02-Correction.md` §7 约定（红/绿/蓝）
- 整句笔记不显示类型标签，展示整句原文与修正

### 3.2 备注编辑

- 备注区默认显示已有备注；无备注时显示占位「添加备注…」
- 点击进入编辑态（textarea），支持修改与清空
- 保存动作：点击「保存」或失焦触发，保存成功后提示「备注已保存」
- 保存失败保留编辑内容并提示重试

### 3.3 返回与导航

- 顶部「← 返回」回到笔记列表页，保留列表的筛选与滚动位置（浏览器返回语义）

### 3.4 来源报告（可选增强）

- 语块笔记若需查看上下文，提供「查看原始纠错报告」入口，跳转纠错主页（`pages/02-Correction.md`）并定位到对应纠错消息，本期可标记为 V1.1 增强项

## 4. 字段与数据

> 本页涉及的笔记数据结构由技术选型阶段定义。产品层面：

- 详情数据：该笔记的全部信息（类型、错误原文、最小修正、地道表达、错因解释、创建时间、备注）
- 可编辑项：用户备注（可新增、修改、清空）

## 5. 校验规则与文案

| 规则 | 触发条件 | 文案 |
|------|----------|------|
| 备注保存成功 | 保存成功 | 「备注已保存」 |
| 备注保存失败 | 请求异常 | 「保存失败，请重试」，内容保留 |
| 加载失败 | 详情请求异常 | 「加载失败，请重试」+ 返回 |

## 6. 三态约定

遵循 Overview §四 4.1「全局 UI 状态约定」：

- **加载态**：进入页面展示详情加载指示器
- **空态**：不适用（详情页）
- **错误态**：加载/保存失败提示 + 重试/返回

## 7. 验收标准

- AC-Nd-01：进入页面完整展示该笔记的全部内容
- AC-Nd-02：备注可新增、编辑、清空并保存成功
- AC-Nd-03：保存失败时编辑内容不丢失，可重试
- AC-Nd-04：「返回」回到笔记列表且保留列表筛选/滚动位置
- AC-Nd-05：移动端正常显示（响应式）
