# 笔记列表页需求文档（03-Notes-List）

**所属**：地道英语纠错 · 智能笔记本 | **版本**：V1.2 | **日期**：2026年8月
**对应功能**：F-02 一键记笔记（列表与筛选部分） | **依赖**：`pages/02-Correction.md` §7 错误类型分类

## 1. 页面目标与入口

- **目标**：集中查看所有已保存的错题笔记，支持按错误类型筛选
- **入口**：顶部导航「错题笔记」；纠错页记笔记成功后的跳转链接
- **出口**：点击单条笔记进入笔记详情页（`pages/04-Note-Detail.md`）

## 2. 页面结构

```
┌─────────────────────────────────────────────┐
│ 顶部导航：Logo | 新纠错 | 错题笔记        │
├─────────────────────────────────────────────┤
│ 标题「错题本」 + 笔记总数                     │
│ [类型筛选：全部 | 语法 | 搭配 | 中式英语 | 风格] │
│                                             │
│ 笔记卡片列表（按创建时间倒序）                 │
│  ┌─────────────────────────────────────┐   │
│  │ [类型标签] 错误原文                     │   │
│  │ ✅ 最小修正   🌟 地道表达              │   │
│  │ 时间戳 · 备注预览（如有）              │   │
│  └─────────────────────────────────────┘   │
│                                             │
│ 分页/加载更多                               │
└─────────────────────────────────────────────┘
```

## 3. 功能与交互细节

### 3.1 笔记列表

- 默认按创建时间倒序展示全部笔记
- 每条卡片展示：类型标签、错误原文、最小修正、地道表达、创建时间、备注预览（最多一行，超出省略）
- 顶部展示笔记总数

### 3.2 类型筛选

- 筛选维度为单选：全部 / 语法 / 搭配 / 中式英语 / 风格（分类见 `pages/02-Correction.md` §7）
- 切换筛选后列表即时刷新，URL 同步筛选参数（便于分享/刷新保留状态）
- 筛选结果为空时展示空态

### 3.3 进入详情

- 点击笔记卡片任意区域，跳转笔记详情页（`pages/04-Note-Detail.md`）

### 3.4 空态

- 无任何笔记：展示引导文案 + 「去纠错」按钮跳转纠错主页
- 筛选无结果：展示「该分类下暂无笔记」+ 「查看全部」按钮清除筛选

### 3.5 分页

- MVP 支持基础分页或「加载更多」，一次加载固定数量（如 20 条）
- 加载更多时显示底部加载指示器

## 4. 字段与数据

> 本页涉及的笔记数据结构由技术选型阶段定义。产品层面，列表项需展示以下信息：

- 类型标签（语法 / 搭配 / 中式英语 / 风格）
- 错误原文、最小修正版、地道表达版
- 创建时间、备注预览
- 筛选维度：错误类型（含「全部」）

## 5. 校验规则与文案

| 规则 | 触发条件 | 文案 |
|------|----------|------|
| 加载失败 | 列表请求异常 | 「加载失败，请重试」+ 重试按钮 |
| 筛选为空 | 某类型无笔记 | 「该分类下暂无笔记」 |

## 6. 三态约定

遵循 Overview §四 4.1「全局 UI 状态约定」：

- **加载态**：首次进入展示骨架屏或加载指示器
- **空态**：见 §3.4（无笔记 / 筛选无结果，均带引导动作）
- **错误态**：列表加载失败提示 + 重试

## 7. 验收标准

- AC-N-01：进入页面展示全部笔记，按创建时间倒序
- AC-N-02：可按错误类型单选筛选，筛选结果正确
- AC-N-03：点击笔记卡片进入对应详情页
- AC-N-04：无笔记时展示空态与「去纠错」引导
- AC-N-05：列表加载失败可重试
- AC-N-06：笔记总数与列表条数一致
- AC-N-07：移动端列表正常显示（响应式）
