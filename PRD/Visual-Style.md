## 一、设计基调

- **风格关键词**：清新、知性、专业、有温度
- **定位**：「会帮你记住每一个错误的 AI 英语教练」——科技可信与学习温度平衡，避免冷冰冰的纯工具感
- **原则**：极简主义、即时反馈、渐进式披露（与 Overview §二 一致）

## 三、字体

- **中文字体**：`PingFang SC`（苹方）· 系统字体栈 `-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`
- **英文字体**：`Inter` 或 `system-ui`；等宽/代码内容用系统 monospace
- **MVP 不引入 web 字体**：用系统字体栈，保证加载性能与跨端一致
- **字重**：标题 600，正文 400
- **行高**：正文 1.6

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 30px | 600 | 页面品牌主标题 |
| H1 | 24-26px | 600 | 页面/卡片标题 |
| H2 | 20px | 600 | 区块标题 |
| Body | 14-15px | 400 | 正文 |
| Caption | 12-13px | 400 | 辅助说明 |

## 五、组件色约定

| 组件 | 规范 |
|------|------|
| **主按钮** | 背景 `#0ca678`，hover `#12c493`，文字白色；禁用 `#99f0d8` |
| **次按钮** | 白底 + `#ced4da` 描边，文字 `#343a40` |
| **输入框** | 背景 `#f8f9fa`，描边 `#ced4da`；聚焦描边 `#0ca678`；错误描边 `#fa5252` |
| **链接** | `#0ca678`，hover `#0b8a63` |
| **中式英语标记** | 背景 `#fff4e6`，描边 `#ffd8a8`，文字 `#e8590c`，用于中式英语卡片区分 |
| **地道进阶标记** | 背景 `#f3f0ff`，描边 `#d0bfff`，文字 `#5f3dc4` |

| **错误反馈** | 背景 `#ffe3e3`，文字 `#c92a2a` |
